# 02 — 15영업일 GraphRAG PoC 실행계획 및 산출물 기준

> 기준 아키텍처: [01_GraphRAG_프로젝트_아키텍처_초안.md](01_GraphRAG_프로젝트_아키텍처_초안.md)
> 추진 기준: 종합계획서 1. 추진 배경·목표 및 2. PoC 범위·핵심 산출물
> 상태: 실행 준비 기준선. 권역·직무·기간·출처·이용 조건은 승인 전 미확정이다.

## 1. 목표와 해석 경계

승인된 채용공고의 구조화된 필드와 서술 근거를 한정된 권역·직무·기간에 연결해, 그래프 관계·집계 검색과 벡터 기반 서술 검색의 기술적 타당성·근거 추적성·데모 가능성을 검증한다. PoC는 부울경 청년 전체의 선호·유출 원인, 기업 구인난의 인과관계, 전체 노동시장의 임금 격차, 취업·정착률 개선 또는 정책 효과를 입증하지 않는다. 승인된 청년 비식별 집계가 없으면 청년 선호 비교를 제외한다.

## 2. 범위 및 완료 기준

| 항목 | PoC 기준 | 중단·범위 변경 조건 |
| --- | --- | --- |
| 지역·직무·기간 | 지역 1곳, 직무군 1~2개, 합의된 관측 기간 | Day 2까지 합의 실패 시 실데이터 분석 대신 합성 데이터 데모 |
| 채용 데이터 | 출처 이용 승인을 받은 공고. 500건은 확보 가능성 검토 후 목표 확정 | 무단 크롤링·재배포·외부 전송 금지. 수량보다 데이터 계약·품질 우선 |
| 설문/인터뷰 | 승인된 비식별 집계만 선택 사용 | 동의·목적·분모·소수 셀·재식별·보관 승인 미완료 시 제외 |
| 검색 기능 | 허용 필터/템플릿, 그래프 집계, 근거가 연결된 서술 검색 | 자유 Text2Cypher, 원인 단정, 개인 응답 질의, 자동 정책 처방은 제외 |

| UI | 출처·표본 범위·결측·한계가 보이는 로컬 데모 | 운영 배포는 범위 밖 |

**최종 통과 기준:** (1) 이용 승인과 범위 기록, (2) 재현 가능한 적재·검수와 원문 근거 추적, (3) 고정 질의의 결과 및 결정론적 집계 일치, (4) 출처·표본 범위·결측·한계 표시, (5) 부적절한 질의·빈 결과·오류의 안전한 처리, (6) 데모 실행 절차와 미해결 위험 보고.

## 4. 핵심 산출물 목록

1. 범위·승인 기록: 권역, 직무군, 기간, 출처, 이용/외부 전송 조건, 책임자, 제외 데이터.
2. 버전 고정 데이터 계약과 샘플: 원문, 정규화 결과, 결측 상태, 출처 ID, 원문 인용 위치, 검수 이력.
3. 재현 가능한 적재·검수 흐름: 입력 검증, 중복·범위 검사, 격리/오류 보고, 재적재 절차.
4. 지식그래프 및 검색 기능: 그래프 모델, 제한된 조회 템플릿, 선택적 벡터 인덱스와 버전 동기화.
5. 근거 기반 데모: 검색/답변, 인용, 표본 범위, 미기재·제외 건수와 방법론 한계.
6. 검증·시연 자료: 고정 질의, 기대 근거·결과, 테스트 보고서, 시연 시나리오 및 실행 안내.
7. 결과·후속 단계: 달성 기준, 품질 한계, 보안·이용 리스크, 확대/보류 판단 및 추정 일정.

## 5. 우선 질의와 통계 출력 원칙

- 특정 권역·기간의 승인 공고에서 직무·기술·복지 표기가 어떻게 나타나는가?
- 급여 명시 공고만 대상으로 하한 급여를 단위와 표본 수를 밝혀 요약할 수 있는가?
- 비교 범위에서 공통·차별 기술과 각 근거 공고를 식별할 수 있는가?
- 근거가 없거나 질문 범위를 벗어나면 미확인으로 반환하는가?

모든 통계는 공고 단위의 분모·단위·기간을 기록한다. 공고에서 관찰한 빈도를 전체 기업/청년 모집단의 특성으로 일반화하지 않는다. 급여 협의·미기재·단위 불명은 수치 집계에서 제외하고 별도 건수로 표시한다. 서로 다른 단위·표본 정의의 평균을 합치지 않는다.

## 6. 현재 상태

저장소의 로컬 구현은 PoC 착수용 스캐폴드다. `data/demo_jobs.jsonl`은 합성 예시이며 실제 채용시장 근거로 사용하지 않는다. Day 1~2 승인 게이트 전에는 크롤러, 실데이터 유입, 외부 API, 자격증명을 연결하지 않는다.
