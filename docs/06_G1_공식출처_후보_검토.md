# 06 — G1 공식 출처 후보 1차 검토

> 상태: 프로젝트 관리자의 G1 내부정책 승인 확인. 공식 목록 재확인 완료, 개별 출처 권한 검증 미완료 (`pending`). 포털 검색 목록에 나타난 후보 메타데이터만 확인했으며, 데이터셋 상세 권한·이용약관을 확인하거나 샘플을 수집한 것이 아니다.
> 승인 정책: [05 G0/G1 작업 기준](05_G0_G1_작업기준_및_G2_착수.md).

## 1. 1차 후보

| 항목 | 확인 내용 |
| --- | --- |
| 후보명 | 공공데이터포털 검색 결과의 `채용정보 API - 채용정보` |
| 제공기관 | 한국고용정보원(검색 결과 표시) |
| 공식 목록 URL | https://www.data.go.kr/tcs/dss/selectDataSetList.do?dType=API&keyword=%EC%B1%84%EC%9A%A9%EC%A0%95%EB%B3%B4 |
| 사용자가 제공한 API 안내 URL | https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do |
| 검색 결과 설명 | 여러 유형의 구인정보 구성을 위한 채용정보 API라고 소개됨 |
| 포털 목록 표시 정보 | 제공기관 한국고용정보원, 수정일 2025-07-21로 표시됨. 목록에서 제목·소개·제공기관을 확인했으나 상세 API 문서는 열람하지 못함 |
| G0 적합 가능성 | 채용공고 API 후보이므로 승인된 부산·SW/AI·최근 게시일 질의의 필드 가용성을 확인할 가치가 있음 |
| 안내 URL 접근 결과 | 페이지 조회에서 API 안내 내용 대신 Work24 비밀번호 설정/확인 관련 화면이 반환됨. API 약관·문서 본문은 확인되지 않음 |
| 현재 상태 | `pending` — 정확한 데이터셋 상세 URL/식별자, 약관/라이선스, 필드, 보존·재사용 조건을 아직 검증하지 않음 |

위 확인은 공식 목록에서 출처 후보와 표시 메타데이터를 재확인한 결과일 뿐, 이 API가 부산 공고를 제공하거나 본문·게시일·실제 근무지·직무를 필요한 수준으로 제공한다는 확인이 아니다. 목록의 수정일은 포털 표시값이며 본 검토의 확인일과 혼동하지 않는다. 상세 페이지를 확인하지 못했으므로 권한·필드 판정은 모두 미확인이다. 포털 공개, 활용신청 건수, API 키 발급 가능성은 본 PoC의 저장·분석·인용 허가를 증명하지 않는다.

## 2. G1 통과 전 필수 확인

공식 데이터셋 상세 페이지와 제공기관의 최신 약관/문의 답변에서 아래 항목을 출처별로 확인한다.

- [ ] 상세 페이지의 정확한 데이터셋 식별자, 제공기관, API 문서·최신 갱신일.
- [ ] 부산 실제 근무지 필터/필드, 게시일, 직무/직종 코드, 공고 ID, 본문·상세내용의 존재 및 의미.
- [ ] 부산 및 게시일 90일 범위로 필요한 필드를 조회할 수 있는가? 요청량·페이지 제한은 무엇인가?
- [ ] API 응답의 저장, 로컬 복제, 정규화, 내부 분석, 결과 화면 및 짧은 원문 인용이 각각 허용되는가?
- [ ] 데이터/본문의 재배포와 외부 처리 조건. 프로젝트 정책상 재배포와 외부 처리는 금지이므로 실제로 수행하지 않는다.
- [ ] 이용신청/인증키가 요구되는 경우 승인 주체·절차·서비스키 취급을 확인한다. 키는 소스·문서·로그에 남기지 않는다.
- [ ] 보존기간, 이용 종료/철회 시 원문·정제본·색인·백업 삭제 조건과 담당자를 정한다.
- [ ] 개인정보·연락처 등 불필요 정보가 포함되는지, 최소화·격리 방안이 필요한지 확인한다.

약관이나 API 문서가 원문 저장·내부 분석·인용을 명시적으로 다루지 않으면 제공기관에 서면으로 질의한다. 회신 전까지 해당 항목은 `unknown`이며, 샘플 요청·다운로드·적재는 하지 않는다.

## 3. 판정 규칙

- **승인:** 제공기관·권한 근거가 확인되고, G0에 필요한 범위와 필드 및 내부 저장/분석 방법이 허용되며, 보존·삭제 조건도 충족할 때만 출처별 G1 승인 기록을 만든다.
- **조건부 보류:** API는 맞지만 본문 저장·인용·보존 중 하나가 불분명하면 `pending`. 가능한 필드만 쓰는 축소 범위를 별도 승인하기 전까지 수집하지 않는다.
- **제외:** 부산 실제 근무지나 게시일 등 분석 핵심 필드가 없거나, 필요한 저장·분석이 금지되거나, 권리자 확인이 불가능하면 `blocked`로 처리하고 대체 후보를 찾는다.

## 4. G0 통과 후 G1 진행 기록 및 다음 순서

### 현재 필요한 증빙

사용자가 제공한 Work24 안내 URL은 기록했으나, 조회 결과에 API 안내나 이용조건이 표시되지 않아 아직 출처 권한의 근거로 판정할 수 없다. G1을 이어가려면 다음 자료 중 접근 가능한 것을 제공해 주세요.

- 공공데이터포털의 해당 API **상세 페이지 URL** 또는 데이터셋 식별자와 API 문서 링크.
- Work24 API 안내를 정상적으로 볼 수 있는 공개 링크, 비밀정보를 제거한 화면/문서 발췌, 또는 공식 API 약관·라이선스의 관련 조항.
- API 응답의 로컬 저장, 정규화, 내부 분석, 화면 표시·짧은 인용, 요청량, 보존·삭제 조건을 확인할 수 있는 공식 문서.
- 문서에 명시되지 않은 권한이 있다면 한국고용정보원/권한자에게 받은 서면 답변. 민감정보·인증키·토큰은 공유하지 말고 가린 상태로 필요한 내용만 전달.

확보 가능한 공식 문서부터 대조하되, 하나라도 권한·필드·보존 측면에서 불명확하면 해당 항목은 `unknown`/`pending`으로 유지한다. 관리자 차원의 프로젝트 승인을 출처 권리자의 허가로 간주하지 않는다.

G0 범위는 [08 G0 분석 범위 결정안](08_G0_범위_결정안.md)에 따라 프로젝트 책임자가 승인했다. 프로젝트 관리자는 G1의 내부 정책(승인된 목적·최소 수집·외부 처리/재배포 금지 등)도 승인했으나, 이 승인은 한국고용정보원 또는 다른 제3자의 이용 허가를 대신하지 않는다. 공식 목록 URL에서 후보명·제공기관·목록상 수정일만 확인했고 사용자가 제공한 Work24 URL 조회에서도 API 안내·이용조건을 확인하지 못했다. 따라서 이 후보의 출처별 G1 상태는 계속 `pending`이며, 데이터 다운로드·인증키 발급/API 호출·샘플 요청은 하지 않았다.

1. 공식 포털 목록에서 후보의 상세 페이지 링크를 확보하고, 정확한 상세 URL·데이터셋 식별자·API 문서·약관/라이선스를 기록한다.
2. 부산 실제 근무지, 게시일, 직무, 원천 ID, 본문/상세내용과 조회 필터·페이지 한도 등 필요한 필드와 기능을 문서만으로 확인한다. 불명확한 권한은 한국고용정보원에 서면 질의한다.
3. 각 권한 항목을 `yes/no/unknown`으로 기록하고 근거 식별자와 확인일을 남긴다. 확인할 수 없는 사항은 추정으로 승인하지 않는다.
4. 권한 있는 승인자가 저장·정규화·내부 분석·인용·보존·삭제 조건을 확인하기 전까지 레지스트리에 `approved`로 등록하거나 데이터를 취득하지 않는다.
5. G1 통과 뒤에만 요청 상한을 최대 50건 또는 제공기관이 허용한 더 낮은 수량으로 제한한 G2 파일럿을 별도 실행한다.
