# 08 — G0 분석 범위 결정안

> 상태: **승인 대기**. 종합계획의 G0 게이트를 통과하기 위한 책임자 확인용 초안이다. 아래 기준은 기존 작업안에서 가져온 제안이며, 사용자의 명시적 확인 전에는 확정 범위로 취급하지 않는다. G0 승인만으로 출처 이용 권한이나 실데이터 수집이 승인되는 것은 아니다.
> 기준 문서: [02 15일 실행계획](02_PoC_15일_실행계획.md), [04 G0/G1 결정 가이드](04_G0_G1_결정가이드.md), [05 G0/G1 작업 기준](05_G0_G1_작업기준_및_G2_착수.md).

## 1. 승인 요청 요약

아래 제안에 동의하면 각 항목을 확인해 G0 범위를 확정한다. 수정이 필요한 항목은 해당 행의 제안 내용을 바꿔 회신한다. 날짜·승인 기록은 실제 결정 시 기입하며 임의로 채우지 않는다.

| 결정 항목 | 제안 범위 | 승인 상태 |
| --- | --- | --- |
| 목적 | 승인된 채용공고를 대상으로 직무·요구 기술·복지·근무조건의 관찰 양상을 근거와 함께 탐색하고, 데이터 계약·검색·근거 추적의 기술적 타당성을 검증하는 내부 PoC | 확인 필요 |
| 핵심 질문 | (1) 범위 내 공고에서 어떤 직무·기술·복지 조건이 관찰되는가? (2) 급여가 명시되고 단위가 비교 가능한 공고는 몇 건이며 급여 범위는 어떠한가? (3) 각 관찰을 원천 공고와 필드 근거로 추적할 수 있는가? | 확인 필요 |
| 사용자·의사결정 목적 | 프로젝트 책임자 및 PoC 구현·검토 담당자의 내부 기술 검토. 정책·채용 의사결정을 자동으로 내리지는 않음 | 확인 필요 |
| 권역 | 부산광역시. 기업 본사 주소가 아닌 공고의 실제 근무지가 부산으로 확인되는 경우만 포함 | 확인 필요 |
| 직무군 | SW/AI 관련 1개 그룹. 소프트웨어 개발 및 데이터/AI 업무가 공고 내용상 명확한 경우에 한함 | 확인 필요 |
| 관측 기간 | 수집 시작일 직전 90일의 게시 공고. 실제 시작일·종료일은 G0 및 G1 승인 뒤, 취득 전에 KST 기준으로 기록 | 확인 필요 |
| 분석 단위 | 출처별 원천 공고 ID 기준 공고 1건. 같은 ID 중복은 제거하고, ID가 다른 재게시 의심 건은 별도 검토 | 확인 필요 |
| 포함·제외 | 근무지·게시일·직무 범위가 확인되는 공고를 주 분석에 포함. 위치·직무 불명확 건은 주 분석에서 제외하고 결측/제외 수를 기록 | 확인 필요 |
| 급여 처리 | 원문·상태·단위를 보존. 명시되어 있고 단위가 같은 데이터만 수치 비교; 미기재·협의·단위 불명은 0으로 대체하지 않음 | 확인 필요 |
| 결과물 | 표본·기간·출처·결측을 밝힌 검색/집계 결과와 인용 근거, 품질·안전성 평가 및 한계 보고 | 확인 필요 |

## 2. 명시적 해석 한계와 제외 범위

이 범위의 공고 자료는 구인 측 게시 내용만 관찰한다. 이를 청년 전체의 선호·구직 행동, 기업의 실제 구인난이나 그 원인, 인과관계, 취업·정착률, 정책 효과 또는 부울경 전체 노동시장으로 일반화하지 않는다. 승인된 청년 비식별 집계가 별도로 확인되지 않는 한 구직자 선호와 기업 수요의 직접 비교는 하지 않는다.

이력서, 개인 구직자 정보, 설문 개인 원자료, 로그인·접근 제한을 우회해 얻은 자료, 권한이 확인되지 않은 검색결과·미러 자료는 범위 밖이다. 원문 저장·인용 여부도 출처별 G1 허가 조건을 따르며, G0 승인만으로 허용되지 않는다.

## 3. G0 통과 체크

- [ ] 핵심 질문과 내부 사용 목적을 책임자가 확인했다.
- [ ] 권역·실제 근무지 기준·직무군과 경계 사례를 확정했다.
- [ ] 게시일 기준 기간, 날짜 확정 시점, 누락·재게시 처리를 확정했다.
- [ ] 분석 단위·포함/제외·급여·결측 처리를 확정했다.
- [ ] 결과물과 일반화하지 않을 해석 한계를 확인했다.
- [ ] 책임자, 승인자, 결정일, 보류 항목 담당자/기한을 기록했다.

| 승인 기록 | 값 |
| --- | --- |
| 결정자/승인자 | 미기록 — 확인 필요 |
| 결정일 및 기준 시간대 | 미기록 — 확인 필요 |
| 결정 상태 | `pending` |
| 미해결 항목·담당자·기한 | 미기록 — 확인 필요 |

**현재 판정:** G0 미통과(승인 대기). 따라서 G1 후보 검토는 문서·약관 확인 준비까지만 가능하며, 출처 승인이나 샘플 취득·실데이터 적재·G2 파일럿으로 진행하지 않는다. G0 승인 뒤에도 출처별 G1 승인과 저장·보존 조건 확인이 선행되어야 한다.

## 4. 다음 단계

1. 프로젝트 책임자가 위 표를 승인하거나 수정한다.
2. 승인 사항과 결정일을 이 문서에 기록하고 G0 상태를 `approved`로 바꾼다.
3. G0 승인 후 후보 출처의 최신 약관·필드·저장/분석/인용·보존/삭제 조건을 출처별로 검토한다. 미확인 권한은 `pending`으로 유지한다.
4. 최소 한 출처의 G1이 승인된 경우에만 수량·필드·보존기한을 사전 확정한 제한적 G2 파일럿을 별도 승인받는다.
