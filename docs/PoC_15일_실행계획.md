> 상태: 실행 준비용 기준선. 권역·직무·기간·출처·이용 조건은 승인 전 미확정이며, 이를 추정해 확정하지 않는다.

## 1. PoC 목표 및 해석 경계

**목표:** 승인된 채용공고의 구조화된 필드와 서술 근거를 한정된 권역·직무·기간에서 연결하여, 그래프 기반 관계·집계 검색과 벡터 기반 서술 검색의 기술적 타당성, 근거 추적성, 데모 가능성을 15영업일 안에 검증한다.

**PoC에서 확인할 것:** 수집 가능성과 이용 조건, 스키마·정규화 품질, 공고 ID와 원문 근거 연결, 검색 재현성, 결측 보존, 제한된 대화형 데모의 안정성.

**PoC가 입증하지 않는 것:** 부울경 청년 전체의 선호·유출 원인, 기업 구인난의 인과관계, 전체 노동시장의 임금 격차, 취업·정착률 개선 또는 정책 효과. 승인되고 방법론이 검증된 청년 비식별 집계가 없으면 청년 선호와의 비교 기능은 제외한다.

## 2. 범위 및 완료 기준

| 항목 | PoC 기준 | 범위 변경/중단 조건 |
| --- | --- | --- |
| 지역·직무·기간 | 지역 1곳, 직무군 1~2개, 합의된 관측 기간 | Day 2까지 합의 실패 시 지역·직무별 실데이터 분석을 중단하고 합성 데이터 데모로 한정 |
| 채용 데이터 | 출처 이용 승인을 받은 공고. 500건은 목표치가 아니라 확보 가능성 확인 후 확정할 상한 목표 | 무단 크롤링·재배포·외부 전송 금지. 유효 샘플 부족 시 수량보다 데이터 계약과 품질 검증 우선 |
| 설문/인터뷰 | 승인된 비식별 집계만 선택적으로 사용 | 동의·목적·분모·소수 셀·재식별 위험·보관 및 이용 승인이 미완료면 제외 |
| 기능 | 허용된 필터·템플릿 검색, 그래프 조회/집계, 근거가 연결된 서술 검색, 출처·한계 표시 | 자유 Text2Cypher, 자동 정책 처방, 원인 단정, 개인 응답 질의는 범위 밖 |
| 저장소/모델 | Neo4j·벡터 저장소·LLM은 보안·비용·이용 조건 승인 후 선택. 초기 실행은 로컬 JSONL 기반 검증 가능 | 외부 전송 승인 전 실데이터를 외부 모델·API에 보내지 않음 |
| UI | 검색, 결과, 인용·출처, 표본 범위·결측·한계가 보이는 로컬 데모 | 배포/서비스 운영은 PoC 범위 밖 |

**최종 통과 기준:** (1) 데이터 이용 승인과 범위 기록, (2) 재현 가능한 적재·검수와 원문 근거 추적, (3) 고정 테스트 질의에서 검색 결과 및 결정론적 집계 일치, (4) 답변마다 출처·표본 범위·결측·제한 노출, (5) 부적절한 질의·빈 결과·DB 오류의 안전한 처리, (6) 데모 실행 절차 및 미해결 위험 보고.

## 4. 핵심 산출물 및 검수

1. **범위·승인 기록:** 권역, 직무군, 기간, 출처, 이용/외부 전송 조건, 책임자, 제외 데이터.
2. **버전이 고정된 데이터 계약과 샘플:** 원문, 정규화 결과, 결측 상태, 출처 ID, 원문 구절/위치, 검수 이력.
3. **재현 가능한 적재·검수 흐름:** 입력 검증, 중복·범위 검사, 격리/오류 보고, 재적재 절차.
4. **지식그래프 및 검색 기능:** 명시된 모델, 제한된 조회 템플릿, 해당 시 벡터 인덱스 및 버전 동기화.
5. **근거 기반 데모:** 질문·필터·답변/검색 결과, 인용, 표본 범위, 미기재·제외 건수와 방법론 한계 표시.
6. **검증·시연 자료:** 고정 질의 세트, 예상 근거/결과, 테스트 리포트, 데모 시나리오, 실행·중단 안내.
7. **PoC 결과·다음 단계:** 달성 기준, 데이터 및 검색 품질 한계, 보안·이용 리스크, 확대/보류 판단과 추정 일정.

## 5. 우선순위 질의 및 안전한 출력

- 특정 권역·기간의 승인 공고에서 직무/기술/복지 표기가 어떻게 나타나는가?
- 급여가 명시된 공고만 대상으로 하한 급여를 단위와 표본 수를 밝혀 요약할 수 있는가?
- 두 선택 범위의 공고에서 공통·차별 요구 기술이 무엇이며, 각 결과가 어느 공고에서 왔는가?
- 검색 결과가 없거나 근거가 부족할 때 미확인으로 반환하는가?

모든 집계는 공고 단위의 분모·단위·기간을 기록한다. ‘공고에서 관찰된 빈도’와 ‘전체 기업/청년 모집단의 특성’을 혼동하지 않는다. 급여 협의·미기재·단위 불명은 수치 집계에서 제외하고 별도 건수로 표시한다. 평균 또는 비교치는 서로 다른 단위·표본 정의를 섞지 않는다.

## 6. 현재 실행 상태

- 저장소에 만든 로컬 기반 구현은 PoC 실행을 시작하기 위한 **스캐폴드**이며, 승인된 실제 데이터 수집이나 Neo4j/벡터 저장소/LLM 연동을 의미하지 않는다.
- `data/demo_jobs.jsonl`의 모든 레코드는 합성 예시다. 화면·보고서·평가에서 실제 채용시장 근거로 사용하지 않는다.
- Day 1~2 승인 게이트를 통과하기 전에는 크롤러, 실데이터 인입, 외부 API 호출, 서비스 자격증명 연결을 진행하지 않는다.
