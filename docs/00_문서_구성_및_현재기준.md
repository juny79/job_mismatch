# 00 — 문서 구성 및 현재 프로젝트 기준

## 현재 목적

현재 구현·후속 계획의 기준 목적은 개인이 직접 제공하고 확인한 이력 정보와 희망 조건을 근거가 확인되는 채용공고와 비교해, 조건 일치와 확인 필요 항목을 설명하는 **비저장 일자리 탐색·추천 기능**이다. 추천은 취업·합격 가능성을 예측하지 않으며, 이력에 적히지 않은 내용은 역량 부족을 뜻하지 않는다.

현재 추천 흐름은 합성 자료 기반의 로컬 기능 검증용이다. 사용자는 고용24 API 인증키 발급 및 저장소 루트 `.env` 저장을 보고했고, 목록 API 명세도 제공했다. 그 명세를 처리하는 격리된 XML 클라이언트와 모의 테스트는 구현했으나, 앱·DB에는 미연동이며 인증키를 읽거나 인증된 API 호출을 하지 않았다. 인증키 발급만으로 출처 이용 허가가 되지 않는다. 실데이터 연결이나 공개 서비스 승인이 완료된 상태도 아니다. 특히 08번에 기록된 G0는 원래 공고 관찰·검색 범위의 승인 기록이며, 개인 이력 기반 추천 목적까지 승인한 것으로 해석하지 않는다. 추천 목적의 실제 데이터 사용 전에는 G0 범위 보완과 출처별 G1 확인이 필요하다.

## 초기 범위 기록과 구버전 처리

- [01 아키텍처](01_GraphRAG_프로젝트_아키텍처_초안.md)와 [02 15일 PoC 계획](02_PoC_15일_실행계획.md)은 초기 공고 분석·GraphRAG PoC 기준이다. 현재 제품 방향과 충돌하면 13·14번과 최신 코드 상태를 우선한다.
- [08 G0 범위 결정안](08_G0_범위_결정안.md)은 당시 승인된 분석 범위를 보존하는 결정 기록이다. 이를 고쳐 현재 추천 목적까지 승인된 것처럼 보이게 하지 않는다. 필요한 범위 변경은 별도 승인 기록으로 남긴다.
- 번호 없는 [초기 아키텍처](GraphRAG_프로젝트_아키텍처_초안.md) 및 [초기 15일 계획](PoC_15일_실행계획.md)은 번호가 붙은 기준본에 의해 대체된 보관본이다.
- [초기 가이드·설계·구현 자료](부울경%20청년%20일자리-기업%20미스매칭%20GraphRAG%20챗봇%20가이드,%20설계%20및%20구현.md)는 예전 아이디어를 보존한 자료일 뿐 현행 계획이 아니다. 해당 문서에 있는 임의 수집, 인과 원인 추정, 무근거 수치, 자유 Text2Cypher, 외부 LLM 사용 등의 예시는 현재 안전·권한 기준과 맞지 않으므로 실행하지 않는다.
- [종합계획서](부울경%20청년%20일자리-기업%20미스매칭%20GraphRAG%20챗봇%20종합계획서.md)는 원본 참고 자료다. 구체적 범위·권한·구현 상태는 번호가 붙은 결정 및 현행 기준 문서를 따른다.

## 변경 원칙

문서 간 상태가 다르면 최신 코드와 13·14번을 현재 기능 기준으로 삼고, 승인·권한 사실은 해당 결정 기록에서 확인한다. 계획·샘플·합성 테스트를 실데이터 이용 승인이나 추천 품질의 증거로 표현하지 않는다. 더 이상 적용하지 않는 문서는 무단 삭제하거나 승인 기록을 덮어쓰지 않고, 대체 문서·상태·이유를 명시한다.
