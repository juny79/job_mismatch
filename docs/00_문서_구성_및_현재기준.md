# 00 — 문서 구성 및 현재 프로젝트 기준

## 현재 목적

현재 프로젝트는 **부산·울산·경남(부울경) 구직자가 단일 챗봇과 대화하거나 이력서(PDF/DOCX/TXT)를 업로드하면, 클라우드 DB(Neon PostgreSQL)에 적재된 부울경 채용공고를 인메모리 GraphRAG 지식 그래프로 연결·분석하여 맞춤형 채용공고를 추천하는 웹 애플리케이션**이다. 추천은 취업·합격 가능성을 예측하지 않으며, 구직자가 편리하게 본인 조건과 보유 기술·자격증에 부합하는 공고를 찾고 원문 근거를 확인하도록 돕는다.
