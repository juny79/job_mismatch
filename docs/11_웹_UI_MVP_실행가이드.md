# 11 — 읽기 전용 웹 UI MVP 및 실행 가이드

> 상태: 로컬 실행 가능한 웹 UI MVP. 합성 데이터로 화면·검색 흐름을 확인할 수 있다. 실제 자료의 이용 권한 승인, 운영 배포용 인증·접근통제 및 TLS는 포함하지 않는다.
> 관련 기준: [07 통합 흐름 및 로컬 GraphRAG 데모](07_통합흐름_로컬_GraphRAG_데모.md), [09 G2 소량 파일럿 착수안](09_G2_소량_파일럿_착수안.md).

## 1. 구현 범위

`src/app/web.py`는 Python 표준 라이브러리 HTTP 서버와 검색·그래프·품질 모듈을 연결한다. UI에서 키워드 검색, 그래프 데모, 설명 가능한 lexical+graph 하이브리드를 선택할 수 있다. 하이브리드는 필드 가중치와 그래프 경로 점수를 결합한 초기 휴리스틱이며, 결과에 점수·매칭 필드·그래프 경로·evidence를 표시한다. 임베딩이나 LLM 생성은 사용하지 않는다. 데이터는 서버 시작 시 JSONL로부터 읽고 UI는 읽기 전용으로 동작한다.

- 검수 완료 레코드만 검색 결과와 집계에 노출한다.
- 합성 데이터는 `--allow-synthetic`을 명시해야 로드한다. 합성 표시와 안내를 UI에서 유지한다.
- 비합성 데이터는 기존 출처 레지스트리 검증에서 승인된 출처만 로드한다.
- 결과가 없으면 빈 결과로 응답하고 근거 없는 내용을 생성하지 않는다.
- 검색 질의는 서버 access log에 남기지 않는다. 응답에는 no-store 및 기본 보안 헤더를 적용한다.

## 2. 로컬 실행

저장소 루트에서:

```bash docs/11_웹_UI_MVP_실행가이드.md
python -m src.app.web --data data/demo_jobs.jsonl --allow-synthetic --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 연다. 종료는 별도 터미널에서 아래 명령으로 서버 프로세스를 찾아 중지할 수 있다.

```bash docs/11_웹_UI_MVP_실행가이드.md
pkill -f '^python -m src.app.web'
```

실제 승인 데이터 파일과 레지스트리를 적용하는 실행 형식은 다음과 같다. 실제 이용 권한이 확인·승인된 후에만 사용한다.

```bash docs/11_웹_UI_MVP_실행가이드.md
python -m src.app.web --data /path/to/approved.jsonl --source-registry /path/to/approved_sources.csv --host 127.0.0.1 --port 8000
```

## 3. 네트워크 공개 관련 제한

`--host 0.0.0.0`은 서버가 모든 네트워크 인터페이스에서 연결을 받게 한다. 현재 MVP에는 사용자 인증, 역할 기반 접근통제, TLS, CSRF 방어, 운영 수준의 요청 제한·모니터링이 없다. 그러므로 이 옵션으로 공용 인터넷에 직접 노출하거나 실제 데이터를 서비스하지 않는다. 원격 데모는 신뢰된 사설 네트워크/VPN과 접근통제된 리버스 프록시 뒤에서만 검토하고, 실제 자료는 출처별 권한·보안 승인이 끝난 뒤에 연결한다.

## 4. 현재 한계와 다음 작업

이 UI는 PoC 시연용이며 모바일 화면을 포함한 기본 반응형 레이아웃만 제공한다. 디자인 시스템, 로그인, 다중 사용자, 데이터 업로드, 관리자 기능, 영속 저장, 운영 배포 구성은 구현하지 않았다. 하이브리드 순위 점수는 초기 휴리스틱일 뿐 검증된 relevance 모델이 아니다. 동의어·형태소·임베딩 기반 검색 및 LLM 답변 생성은 미구현이다. 서버가 시작할 때 데이터를 한 번 로드하므로 JSONL 변경 시 서버를 재시작해야 한다.

다음 작업은 고정 질의 평가기를 실행해 키워드·그래프·하이브리드 기준선을 비교하고, 이후 G1 승인과 API 명세 확보 시 source-specific mapping 및 최대 50건 파일럿을 진행하는 것이다. API 승인을 기다리는 동안에는 합성 회귀 테스트·검색 평가·근거 패키지와 관계별 evidence 개선을 진행한다.
