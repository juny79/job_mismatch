# 14 — 개인 이력 기반 채용공고 미스매칭·추천 전환안

> 상태: 제품 방향 보완 및 로컬 합성 데이터 실험 기준. TXT/Markdown은 브라우저 기본 API로, PDF와 Word DOCX는 CDN에서 필요 시 로드하는 PDF.js/Mammoth를 이용해 브라우저에서 텍스트를 추출한다. 스캔 PDF OCR·구형 DOC 파싱, 개인정보 자동 제거, 실데이터 추천, 계정/프로필 저장은 구현된 것이 아니다.

## 1. 제품 목표

개인이 본인의 개인정보를 제거한 이력 정보를 제공하면, 시스템이 해당 정보를 구조화하고 승인·검수된 최신 채용공고의 요구 조건과 대조해 다음을 돕는다.

1. 이력 입력·수정: 준비된 폼, 짧은 단계형 챗봇 질문, 비식별 이력 텍스트 업로드 중 선택한다.
2. 이력 검토: 자동 추출한 기술·경력 정보를 사용자에게 확인·수정받는다. 추출 결과는 사실로 단정하지 않는다.
3. 미스매칭 설명: 이력에 명시된 정보와 공고 요건의 일치, 미일치, 미확인을 구분한다. 이력에 없는 요건은 실제 능력 부족이 아니라 “이력에서 확인되지 않음”으로 표시한다.
4. 추천: 필수 조건 및 모집 유효성 게이트를 통과한 공고를 이력-공고 기술 비교와 사용자 희망 조건으로 정렬한다.
5. 근거 제공: 공고 출처, 게시/확인 시점, 원문 근거, 조건별 비교를 함께 보인다. 적절한 후보/근거가 없으면 추천을 보류한다.

이 기능은 지원 가능성·합격 확률·취업 성공을 예측하지 않는다. 미기재는 부적격 또는 역량 부족으로 보지 않는다. 자동화된 결과는 사용자가 직접 확인하고 수정한다.

## 2. 데이터 최소화 및 개인정보 경계

- 이름, 연락처, 이메일, 상세 주소, 생년월일, 사진, 주민등록번호, 건강·가족 정보 등은 입력하지 말고 업로드 전에 제거한다. 추천 변수로 민감·보호 특성을 수집하거나 추론하지 않는다.
- 초기 MVP는 계정 없는 세션형 비저장 처리다. 브라우저를 새로고침하거나 대화를 다시 시작하면 입력 상태를 잃어도 되는 설계를 우선한다.
- 지원 파일은 TXT/Markdown/PDF/Word DOCX다. 원문은 브라우저에서만 읽고 서버로 보내지 않는다. PDF.js/Mammoth 라이브러리는 CDN에서 브라우저로 다운로드되며 파일 내용은 CDN으로 전송하지 않는다. CDN을 사용할 수 없는 오프라인 환경에서는 TXT/Markdown을 사용한다. 추출된 최소 기술 키워드만 임시 추천 요청에 포함하고 서버는 저장·로그하지 않는다.
- 개발 시 실제 개인 이력서는 테스트에 사용하지 않는다. 합성 인물과 가짜 이력으로 테스트한다.
- 영속 저장, 로그인, 프로필 재사용, 분석/학습, 제3자 LLM 처리, 서비스 공개는 목적·법적 근거·동의·보존/삭제·보안 검토를 거친 별도 승인 사항이다.

## 3. 입력 채널 및 MVP 계약

### A. 선택형 폼

지역·희망 직무·경력 요약·보유 기술을 사용자가 직접 작성한다. 각 필드의 출처(사용자 자기기재), 확신 여부, 수정 가능성을 유지한다. 합성 MVP에서 비교에 우선 활용하는 프로필 필드는 기술 키워드다.

### B. 단계형 대화 UI

챗봇이 보유 기술, 희망 직무, 경력/프로젝트, 희망 지역을 순서대로 묻고 답을 구조화 폼에 반영한다. 초기 구현은 규칙 기반 질문 흐름이며 LLM 자유대화/자동 추출로 표현하지 않는다. 사용자가 답변을 검토·수정·초기화한 뒤 매칭을 시작한다.

### C. 비식별 이력 텍스트 업로드

초기 MVP는 최대 5MB의 `.txt`/`.md`/`.markdown`/`.pdf`/`.docx` 파일을 브라우저에서 처리하고, 고정 기술 사전과 대조해 후보 키워드를 추출한다. PDF는 최대 50페이지의 텍스트 레이어를 읽으며, Word는 DOCX 형식을 지원한다. PDF.js/Mammoth 코드는 CDN에서 필요 시 내려받고 파일 원문은 외부 서비스나 서버로 전송하지 않는다. 오프라인에서는 TXT/Markdown을 사용한다. 스캔 PDF의 OCR, 구형 `.doc`, 표/레이아웃을 보존하는 완전한 이력서 파싱, 개인정보 자동 익명화는 지원하지 않는다. 사용자가 추출 결과를 직접 확인·수정하며, 사전 매칭은 데모 수준이므로 누락·오탐 가능성을 알린다.

## 4. 미스매칭·추천 로직

- 후보 공고는 기존 게이트(승인·검수·활성 상태·만료일·최신성·필드 evidence)를 통과해야 한다.
- 이력의 자기기재 기술과 공고의 근거가 있는 요구 기술을 정규화해 비교한다. 결과는 일치 기술, 이력에서 확인되지 않은 공고 기술, 공고 정보 미확인으로 분리한다.
- “이력에서 확인되지 않은 기술”은 실제 능력 결여가 아니다. 사용자 확인을 유도하고, 능력 판정이나 자격 배제 근거로 사용하지 않는다.
- 프로필 기술 포함도는 분모가 확인되는 공고 요구 기술만 사용하고, 근거 없는 필드는 계산에서 제외한다. 해당 지표는 채용 가능성/직무 적합성 확률이 아니다.
- 사용자 희망 조건(지역, 직무, 급여, 근무 형태 등)과 경력-공고 비교 결과는 별개의 축으로 표시한다. 필수 조건 실패는 선호 점수로 상쇄하지 않는다.
- 초기 랭킹은 결정론적·설명 가능한 기준만 사용한다. GraphRAG는 승인 공고 검색 및 관계/근거 후보 생성에 쓰고, 매칭 판단·점수는 코드에서 수행한다.
- 원문 evidence가 부족하거나 모집 유효성을 확인할 수 없으면 `미확인` 또는 추천 보류로 처리한다.

## 5. 현재 구현 진행 현황

- [x] 이력-공고 기술 포함도 및 공고에 있으나 이력에는 기재되지 않은 기술을 결정론적으로 비교하는 로직 추가.
- [x] `/api/recommend`의 일회성 요청으로 후보 프로필 기술을 전달하며 서버 저장을 하지 않는 계약 추가.
- [x] 브라우저에서 TXT/Markdown/PDF/Word DOCX를 읽고 사전 기술을 후보 추출하는 UI 흐름 추가(PDF.js/Mammoth CDN 의존).
- [x] 기술·직무·경력·지역을 단계별 질문으로 받는 규칙형 챗봇 및 직접 입력 폼 추가.
- [x] 결과 설명에서 포함도와 “이력에 미기재(확인 필요)”를 구분하고 미스매칭을 역량 부족으로 단정하지 않도록 고지.
- [ ] 개인정보 자동 제거/식별, 스캔 PDF OCR·구형 DOC 파싱, LLM 대화형 추출, 정교한 직무·경력 매핑.
- [ ] 승인된 실공고 자료에 대한 이력-공고 매칭의 relevance 평가 및 사용자 검증.
- [ ] 사용자 계정, 프로필 저장/재방문, 피드백 활용, 운영 배포 보안.

현재 완료 표시는 합성 자료 기반 로컬 vertical slice 코드의 범위다. 제품 품질·개인정보 보호 인증·실데이터 권한 승인이나 실제 추천 효능을 뜻하지 않는다.

## 6. 단계별 다음 실행

1. **합성 vertical slice 검증:** 기술이 모두/일부/하나도 없는 이력, 공고 기술 evidence 부재, 이력 빈 값, 만료/미승인 공고 사례를 테스트한다.
2. **이력 필드 모델링:** 사용자 자기기재와 추출 후보를 구분하고, 사용자가 확인한 값만 매칭 기준으로 확정한다. 경력·자격은 원천 공고 필드가 승인되고 evidence가 있을 때만 비교한다.
3. **검색·설명 평가:** 고정 합성 세트에서 후보 재현율, 기술 비교 정확성, 결측의 미확인 처리, 최신성/근거 충실도, 보류 정확도를 측정한다. 실사용 성능 주장은 금지한다.
4. **정책 및 출처 게이트:** 목적이 “개인 이력 기반 매칭/추천”으로 바뀌었음을 G0 및 데이터 출처별 G1에 반영한다. 출처가 개인화 추천/화면표시를 허용하지 않으면 해당 자료를 쓰지 않는다.
5. **사용자 파일럿:** 개인정보 처리, 명확한 고지·동의, 수정·삭제, 접근통제, 사건 대응, 실제 사용자 테스트 계획 승인 후 수행한다.

## 7. 완료 기준 및 안전 문구

- 이력 원문이 브라우저 외부로 전송되지 않으며, 요청에 포함되는 필드가 최소화되어 있음을 네트워크/로그 테스트로 검증한다.
- 사용자가 프로필 추출 결과를 확인·수정·초기화할 수 있다.
- 모든 불일치 설명은 공고 evidence에 연결되고, 이력 미기재는 역량 부족이라고 표현하지 않는다.
- 미승인·마감·만료·불확실 공고는 추천 대상이 되지 않거나 불확실성을 명시한다.
- 화면에는 “이력과 공고의 기재 내용 비교이며, 이력 미기재는 실제 능력 부족을 뜻하지 않고, 취업·합격을 예측하지 않는다”는 안내를 둔다.
